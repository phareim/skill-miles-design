# Miles slide templates

A set of ready-to-copy 16:9 slide templates, one per pattern in
[`../../presentation-patterns.md`](../../presentation-patterns.md), built only
from the bundled tokens, components, and assets. Two parallel forms:

| File | What it is | Open with |
|---|---|---|
| `deck.html` | Self-contained HTML deck — 16:9 stage, arrow-key / click nav, dots + counter. The live, pixel-verified reference. | a browser (← → to navigate) |
| `miles-templates.pptx` | The same templates in real PowerPoint — brand theme colours, **Manrope** headings + **DM Sans** body, embedded logos/illustrations/service icons. | PowerPoint / Keynote / Google Slides |
| `build_pptx.py` | Generator for the `.pptx` (so it stays reproducible/reviewable). | `pip install python-pptx && python build_pptx.py` |

## Templates included

Cover (cream / red / burgundy) · illustration cover · agenda (TOC cards) ·
chapter divider · standard content (kicker → heading → body → illustration) ·
service-area intro · all service areas · two-column editorial · red split panel ·
team · tips + vision · closing (pill-nav).

## Notes

- **The official `Miles template 2026.pptx` is the source of truth.** It has
  locked master layouts, real photography, and the full 43-layout set. This
  `.pptx` is a lightweight *system demo / starter* that proves the tokens and
  assets map cleanly into PowerPoint — not a replacement. For a real client
  deck, start from the official master and lift these patterns into it.
- **Fonts:** the `.pptx` references Manrope + DM Sans by name (the official
  template's choice; Gelica can't embed in `.pptx`). Those fonts must be
  installed on the machine that opens the file — they are not embedded.
- **Team portraits** are placeholder cream wells — swap for real black-and-white
  portraits at radius 50%.
- The `.pptx` is regenerated by re-running `build_pptx.py`; edit the script, not
  the binary.
